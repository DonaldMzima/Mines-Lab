## Shared source/access blockers

All 15 games are Not connected. No approved read-only adapter could be built from the evidence available. Each game needs its provider's confirmed stable game/mode IDs, versioned rules, an authorized read-only endpoint/export contract, authentication grant, round/state/completion fields, sanitized authentic fixtures, rate/replay/order guarantees and permission to retain/relay records. Unknown values remain unknown. A Chrome presence marker is not outcome access.

The manual record adapter is implemented and immediately usable for genuine user-provided evidence. It deliberately rejects claims of provider provenance. No gambling account passwords, cookies or session tokens are requested.

## Accuracy and evaluation

No game has independently validated predictive accuracy. Blackjack actions are conditional strategy, not win forecasts; Poker hand ranks are current facts; crash statistics describe past samples. These are not scored as predictions. Hilo directional win events and the supported Dice, Penalty, Keno-all-hit and Towers-survival probability events can be compared to later, exactly linked manual outcomes. The browser groups summary statistics by identical configuration, reports failures, expected baseline, Brier score and Wilson95 uncertainty, and labels every comparison manual/unverified. Existing Mines evaluation remains distinct from confirmed bomb-map display.

Equality and payout assumptions are explicit. Crash records report strict-above and at-or-above frequencies separately because authentic equality settlement remains unresolved. No next round, goalkeeper direction, safe tile, winning flip side, hidden hazard or crash cash-out time is fabricated.
